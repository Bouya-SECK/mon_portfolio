# Portfolio - Développeur Web Junior

Portfolio personnel développé en HTML, Tailwind CSS et JavaScript vanilla.

## Structure du projet

```
portfolio/
├── index.html                  → Page principale
├── assets/
│   ├── css/
│   │   └── style.css           → Styles custom (animations, effets)
│   ├── js/
│   │   └── main.js             → Interactions (menu, scroll, formulaire)
│   ├── images/
│   │   ├── avatar.jpg          → Ta photo de profil
│   │   └── projects/
│   │       ├── projet1.png     → Capture projet 1
│   │       ├── projet2.png     → Capture projet 2
│   │       └── projet3.png     → Capture projet phare
│   └── cv.pdf                  → Ton CV téléchargeable
└── README.md
```

## Lancer le projet

Ouvre simplement `index.html` dans ton navigateur.
Aucune installation requise.

## Personnalisation

1. Remplace `Votre Prénom` par ton prénom dans `index.html`
2. Mets ton email, GitHub et LinkedIn
3. Ajoute ta photo dans `assets/images/avatar.jpg`
4. Ajoute les captures de tes projets dans `assets/images/projects/`
5. Dépose ton CV dans `assets/cv.pdf`
6. Mets à jour l'email dans `assets/js/main.js` (ligne du mailto)

## Déploiement

- **GitHub Pages** : push le dossier sur GitHub → Settings → Pages
- **Netlify** : drag & drop du dossier sur netlify.com
- **Vercel** : importe le repo GitHub sur vercel.com

## Stack

- HTML5
- Tailwind CSS (CDN)
- JavaScript Vanilla
- Google Fonts (Inter + Space Grotesk)
